This is a college project with the plan to create an application that display a list of games that customers can buy/trade in. Staff should also be able to log in and edit/add games in the list and have the capabilities to view the history and details of each customer.

The exercise was to create an application based on a pre-determined scenario that we had to create analysis and design documents containing;






•	Functional & Non-functional requirements

•	MoSoCoW table

•	Textural Analysis

•	CRC Cards

•	Use cases and Detailed use cases

•	UML Design

Once the documentation was completed, the code could begin using the documentation for reference.

The project is still on going so more updates to documentation and code to come.
